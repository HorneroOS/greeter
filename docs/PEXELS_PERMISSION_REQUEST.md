# Pexels permission requests (rights gate, issue #39)

These drafts exist because the Pexels License does not by itself settle the
use this project performs: redistributing transcoded clips inside a
**separate, downloadable media package** for an open-source operating
system's login screen (greeter). Until written permission is recorded in a
manifest's `review.evidence` with `review.distribution: approved`, every
Pexels candidate stays parked in `media/candidates/` and
`scripts/media/fetch.py` refuses to fetch it. Nothing here has been sent
yet; sending is a human decision.

Placeholders to fill before sending: `<SENDER NAME>`, `<SENDER EMAIL>`,
`<PROJECT / ORGANISATION>`, `<DATE>`, and (for creator letters) the single
clip ID that belongs to that creator.

Candidate Pexels video IDs under consideration: 33053999, 37112523, 33665907, 33285416, 18210885, 38921813, 34075564, 36229695, 36783241, 37382809, 37382839.

Scope stated honestly in both drafts: free/open-source OS (HorneroOS),
clips used only as silent login-screen background video, shipped in a
separate downloadable media package (not sold, no standalone clip
redistribution or stock-library use), transcoded to at most 1080p H.264
with audio stripped, attribution in the package `NOTICE` file and an
optional on-screen credit.

## Draft A — to Pexels

Subject: Permission request — redistributing Pexels videos in an open-source OS media package

Hello Pexels team,

I am <SENDER NAME> (<SENDER EMAIL>), writing for <PROJECT / ORGANISATION>,
the HorneroOS project — a free, open-source operating system. Date: <DATE>.

We would like to use the Pexels videos listed below as silent background
video on the system's login screen. The clips would be transcoded (at most
1080p, H.264, audio removed, possibly trimmed/crop-fitted to 16:9) and
shipped inside a separate, freely downloadable media package that users
install alongside the greeter theme. The package is not sold and the clips
are not offered standalone or as a stock library; they play only as
full-screen login backgrounds. Every creator is credited by name in the
package NOTICE file and in the project's media provenance records, and we
can also show an on-screen credit if you or the creators prefer.

The Pexels License permits many uses, but redistributing the videos as part
of a downloadable software package seems close to its redistribution
limits, so we are asking before doing it. Could you confirm whether this
use is permitted as described, or what conditions would make it permitted?

Video IDs: 33053999, 37112523, 33665907, 33285416, 18210885, 38921813, 34075564, 36229695, 36783241, 37382809, 37382839.

Thank you for your time — we are happy to adjust attribution, resolution, or
packaging to meet your requirements, and we will not ship anything before
hearing back.

<SENDER NAME>
<PROJECT / ORGANISATION> — HorneroOS greeter media
